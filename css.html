CSS: شكل صفحات الويب

المقدمة

صفحة HTML دون تنسيق تبدو نصًّا أسود على خلفية بيضاء. وCSS هي اللغة التي تحوّلها إلى تصميم له ألوان وخطوط وتخطيط مرتب.

التعريف

CSS اختصار لـ Cascading Style Sheets أي صفحات الأنماط المتتالية. هي لغة أنماط تصف مظهر عناصر HTML: ألوانها وأحجامها ومواقعها وطريقة عرضها على مختلف الشاشات.

النشأة والتطور

اقترح هوكون فيوم لي فكرتها عام 1994 لفصل الشكل عن المحتوى. صدرت CSS1 توصيةً رسمية في ديسمبر 1996، ثم CSS2 عام 1998، أما CSS3 فتطورت على شكل وحدات مستقلة تضيف كل واحدة منها ميزات جديدة كالتحويلات والحركة والتخطيط المرن.

طرق إضافة CSS

ثلاث طرق: داخل الوسم نفسه بالخاصية style (أقلها تنظيمًا)، أو داخل وسم style في رأس الصفحة، أو في ملف خارجي بامتداد .css يُربط عبر وسم link. الطريقة الثالثة هي الأفضل لأنها تجمع تنسيق الموقع كله في مكان واحد.

القواعد والمحددات

تتكون القاعدة من محدد يختار العناصر وكتلة تضم الخصائص وقيمها. يمكن اختيار العنصر باسم وسمه، أو بصنف .class، أو بمعرّف #id.

h1 { color: #2965f1; font-size: 2rem; }
.card { padding: 1rem; border-radius: 8px; }
@media (min-width: 800px) {
  .card { width: 50%; }
}
أهم المفاهيم

نموذج الصندوق: لكل عنصر محتوى وحشوة (padding) وإطار (border) وهامش (margin). التتالي والأولوية: عند تعارض القواعد يُحسم الأمر بالتحديد ثم بترتيب الكتابة. Flexbox وGrid: نظامان لتخطيط الصفحة في صفوف وأعمدة. الاستعلامات الوسائطية (media queries): تغيّر التنسيق حسب عرض الشاشة لتكون الصفحة متجاوبة.

المميزات والحدود

تفصل الشكل عن المحتوى فيسهل تغيير تصميم موقع كامل بتعديل ملف واحد، وتوفر تجاوبًا مع الهواتف دون لغة إضافية. في المقابل، تتعقد الملفات الكبيرة إن لم تُنظم، وقد يظهر التنسيق بشكل مختلف قليلًا بين المتصفحات.

الخاتمة

CSS هي لغة الجمال في الويب. من يفهم نموذج الصندوق والتخطيط المرن والاستعلامات الوسائطية يستطيع أن يصمم صفحات مرتبة تعمل على كل الأجهزة.
