JavaScript: حركة صفحات الويب

المقدمة

عندما تنقر زرًّا فتظهر قائمة، أو تكتب في خانة فتظهر اقتراحات، فهذه JavaScript تعمل. هي اللغة التي تجعل الصفحة تتفاعل مع المستخدم بدل أن تبقى ساكنة.

التعريف

JavaScript لغة برمجة عالية المستوى تُنفَّذ مباشرة في المتصفح دون تثبيت شيء. وصارت تعمل أيضًا على الخوادم بفضل Node.js. وهي لا علاقة لها بلغة Java رغم تشابه الاسم.

النشأة والتطور

كتبها برندن آيك في شركة Netscape عام 1995 في وقت قصير، وسُميت أولًا Mocha ثم LiveScript ثم JavaScript. وُحِّدت لاحقًا باسم ECMAScript عام 1997، وجاء إصدار ES6 عام 2015 بتحديثات كبيرة مثل let وconst ودوال السهم. وظهرت Node.js عام 2009 فنقلتها إلى الخادم.

الأساسيات

المتغيرات تُعلن بـ let وconst. من الأنواع: النصوص والأعداد والقيم المنطقية والمصفوفات والكائنات. وتتحكم بالتنفيذ الشروط if والحلقات for وwhile، وتُجمع الأوامر المتكررة في دوال.

DOM والأحداث

يحوّل المتصفح صفحة HTML إلى شجرة كائنات تسمى DOM، وتستطيع JavaScript قراءتها وتعديلها. أما الأحداث فهي ما يفعله المستخدم، كالنقر والكتابة والتمرير، وتنتظرها اللغة لتنفذ ردّة فعل.

const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  alert("تم النقر!");
});
المميزات

تجعل الصفحات تفاعلية، وتعمل في كل المتصفحات دون تثبيت، ولها نظام ضخم من المكتبات والأطر مثل React وVue. ويمكن بها بناء الواجهة والخادم بلغة واحدة.

الحدود

لا يصح الوثوق بما يدخله المستخدم دون تحقق منه لأسباب أمنية. وتصعب صيانة الشيفرة الكبيرة إن لم تُنظم، وتختلف سرعة التنفيذ بين الأجهزة.

الخاتمة

JavaScript هي لغة الحياة في الويب. بعد أن تتقن HTML وCSS تأتي هي لتضيف المنطق والتفاعل، وتفتح الباب لتطبيقات الويب كاملة.
