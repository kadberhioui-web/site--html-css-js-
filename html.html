HTML: هيكل صفحات الويب

المقدمة

كل صفحة ويب تراها في المتصفح تبدأ من ملف HTML. هي أول لغة يتعلمها من يريد بناء المواقع، وهي الأساس الذي تُبنى عليه اللغتان الأخريان.

التعريف

HTML اختصار لـ HyperText Markup Language، أي لغة ترميز النص التشعبي. هي لغة ترميز وليست لغة برمجة: لا تحتوي على شروط أو حلقات، وإنما تصف بنية المحتوى بوسوم (tags) يفهمها المتصفح ويعرضها على الشاشة.

النشأة والتطور

ابتكر العالم تيم برنرز-لي اللغة في مركز CERN حوالي عام 1991 ليتبادل الباحثون الوثائق عبر الروابط. تطورت بعد ذلك عبر HTML 4 وXHTML حتى صدر HTML5 توصيةً رسمية عام 2014، وأضاف وسومًا دلالية ودعمًا مباشرًا للصوت والفيديو والرسم. ويتولى تطويرها اليوم WHATWG كمعيار حي يتجدد.

بنية الصفحة

تتكون كل صفحة من جزأين: head للمعلومات غير المرئية كالعنوان والترميز، وbody للمحتوى الظاهر.

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحبا</h1>
  <p>هذه فقرة.</p>
</body>
</html>
أهم الوسوم

العناوين h1 إلى h6، والفقرة p، والرابط a، والصورة img، والقوائم ul وol، والجداول table، والنماذج form وinput. وهناك وسوم دلالية تصف دور الجزء في الصفحة مثل header وnav وmain وsection وfooter.

المميزات

سهلة التعلم، ومدعومة في كل المتصفحات، ومجانية ومفتوحة. والوسوم الدلالية تفيد محركات البحث وقارئات الشاشة لذوي الإعاقة البصرية.

الحدود

لا تتحكم HTML وحدها في الشكل ولا في التفاعل، فصفحتها بلا CSS تظهر بسيطة، وبلا JavaScript تبقى ساكنة. لذلك تُستعمل مع اللغتين الأخريين.

الخاتمة

HTML هي الهيكل الذي لا يقوم موقع بدونه. وإتقان وسومها الأساسية والدلالية هو الخطوة الأولى الصحيحة قبل الانتقال إلى التنسيق مع CSS.
